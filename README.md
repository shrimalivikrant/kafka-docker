# Kafka Docker

A light-weight environment for running Apache Kafka in a Docker container, featuring a dedicated producer application (`demo1`) and a consumer application (`demo2`).

## 📁 Project Structure

```text
kafka-docker/
├── demo1/              # Kafka Producer application
├── demo2/              # Kafka Consumer application
├── docker-compose.yml  # Docker Compose configuration for Kafka
└── README.md           # Project documentation
